# MATRIZ DE CORRESPONDENCIA TÉCNICA PARA REFACTORIZACIÓN DE CÓDIGO
### `idOcultoAnterior` > `idPrimarioActual` (Wix V2 Canónico)

Esta matriz proporciona la correlación campo a campo para realizar labores de búsqueda, reemplazo y refactorización en el código backend (`.web.js`, `.js`, `.jsw`), funciones HTTP (`http-functions.js`), hooks de datos (`data.js`) y controladores de página en Wix Velo:
```javascript
// Patrón de refactorización en consultas Wix Data:
// ANTERIOR:
wixData.query("ServiciosCatalogo").eq("tipoServicio", "APPOINTMENT").find();
// ACTUAL:
wixData.query("ServiciosCatalogo").eq("serviceType", "APPOINTMENT").find();
```
